# 会话与命令

- 每个私聊独立上下文，同群授权用户共享上下文；群回复对所有群成员公开。消息间隔超过两小时且当前上下文估算超过 100,000 tokens 时，在原 thread 先压缩再提交新消息；私聊提示，群聊不发送空闲压缩通知。

- `/new` 中断本会话任务并清空等待任务。私聊后续创建空白 thread；群聊在旧 thread 额外执行总结 turn，使用当前模型及 medium，生成非空、最多 2000 字符的结构化摘要，成功后下条消息携摘要创建新 thread。仅归纳群成员表达及上次交接背景，不归纳 assistant 回复、工具输出、system/developer 指令和群设定，不推断任务完成；这只是对当前可见上下文的提示词约束，不保证绝对角色隔离或完整原始历史覆盖。总结期间不可使用 QQ 活动工具，不发送模型正文或生成图片，只提示状态；要求不调用工具，但不改变 runtime 的工具权限。总结最长 15 分钟（若配置的任务期限更短则取较短值）。总结期间普通消息继续积累，结束后调度已触发批次，`/status` 显示忙碌，`/stop` 可取消。群聊 `/new blank` 可取消总结并直接空白重置、清除交接摘要；私聊不新增此命令。总结失败、超时、取消或输出无效时保留旧 thread，不自动重试，已提交的总结请求不回滚。摘要与待切换状态一并持久保存，跨重启保留；未完成总结不自动恢复。已经待切换时重复 `/new` 不再次总结。摘要作为参考数据参与新群 thread 的完整提示词快照及压缩后补注入，不授权执行旧请求。工作文件、图片索引、模型、群设定及聊天偏好均保留；旧 Codex 历史仍保留。

- `/stop` 中断本会话任务并清空本会话队列；群内任一授权用户均可使用。

- `/status` 查看登录状态、忙碌状态、上下文长度及已提交的用户消息数。上下文长度取当前 thread 最近上报并持久保存的 token 估算，不是累计消耗；已有 thread 但缺少估算时显示“暂未知”。消息数取自 Codex thread 历史，不包含排队消息；普通 slash command 不提交历史，但群聊总结会增加一条内部总结请求，失败或取消后可能仍计入旧 thread；读取失败不影响上下文估算显示。尚未创建或 `/new` 待切换时两者显示 0。群内命令也需要 @ bot。

- `/help` 查看使用方法及全部指令。

- `/model` 从 Codex 获取可选模型列表；`/model <模型ID>` 切换本会话模型，下一轮请求生效，不打断正在运行的任务，也不清空上下文。

- 模型选择按会话持久保存，同群共享，重启及 `/new` 后保留。仅列出支持 `medium` 的非隐藏模型，每轮推理强度固定为 `medium`。

- 私聊与各群并发执行，各聊天独立调度。同一聊天处理中收到的新消息按到达顺序通过 steering 追加到当前 turn，由 runtime 在工具调用结束等可接收输入的位置处理；如果 turn 已结束，则开启下一轮。私聊最多等待 `queue_limit` 条未提交消息（默认 8 条），每条最多 5 张图片、每张 10 MiB；群聊使用持久化历史和批次，不沿用单消息队列限制。任务期限由 `task_timeout` 控制（默认 3600 秒），成功追加消息后重新给予配置的完整期限，追加失败不延长。

- 自动压缩阈值固定为 200,000 tokens，按完整有效上下文统计，不修改模型真实窗口大小。不因上下文过大迁移历史、截断文字或因图片达到 8 MiB 换 thread；原图、图片索引和完整聊天历史保留，压缩不保证移除所有图片或降低总网络流量。上下文大小取 runtime 最近一次 token usage 的近似值，按 thread 持久保存，恢复时接收更新；缺失时最多等待两秒，仍未知则跳过空闲压缩。

- `/compact` 手动压缩原会话，不提交用户消息；会话忙碌时提示稍后重试，无 thread 时不调用模型。私聊的手动、空闲和自动压缩，以及群聊显式 /compact 开始时发送“正在压缩上下文……”；同一压缩事件不重复提示，同轮再次压缩仍提示。`/compact` 保留完成或失败回复。压缩期间新消息排队，受配置的任务期限及 `/stop`、`/new` 控制。空闲压缩明确失败且已结束时继续提交新消息，状态未知时停止任务并退出服务，避免继续使用状态未知的会话。

- 重复消息不重跑；进程崩溃时未完成任务不自动重试。网络断开时发送失败会记录日志，不自动重发不确定的结果。

群内命令需 @ bot，`/status` 的用户消息数在群中表示已提交消息批次。群触发与回复见 [群聊协议](groups.md)，图片保留见 [图片与文件](images.md)，偏好与群设定指令见 [记忆与提示词](memory-prompts.md)。
