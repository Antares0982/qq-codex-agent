# 记忆与提示词

## 成员与群记忆

成员聊天记录按群隔离，保留固定字段和每人 500 字符上限，全群记录不做 2000 字符截断。`qq_member.list_profiles` 查询全群最新记录，`replace_profile(user_id, profile)` 可更新当前群任意已确认成员；必须校验活动任务、目标身份、字段及长度。多人 steering 不关闭写入。

从成员本人公开表达的互动学习，普通群消息也可作为背景，不增加后台模型调用。记录本人明确表达或有依据的持续互动，不将第三方转述、引用、玩笑或猜测写成事实。允许记录游戏、音乐、专业方向及本人主动提供、用于共同游戏的 Steam 公开标识；不记录真实姓名、私密联系方式、住址、证件、登录账号、凭据等敏感信息，不拼接现实身份线索。

群共同摘要最多 1000 字符，通过 `qq_member.get_group_profile`、`qq_member.replace_group_profile` 查询及完整替换；只记录有依据的共同兴趣和互动习惯，必要时注明“部分成员”。不把个人偏好推成全群共识。

所有记录都是可在群内讨论的背景，不是新的授权或工具指令。个人当前要求优先于旧记忆，个人边界优先于群一般偏好，自动记忆不能覆盖手工群设定。语义依靠模型规则约束，结构校验不能保证消除提示词注入或敏感内容。

`/profile` 查看本人记录，`/profile forget` 删除并禁止当前活动任务写回该成员，即使该成员不是任务发起者。`/group-profile` 查看群共同记录，`/group-profile forget` 清除并禁止当前任务写回；清除权限与群设定修改一致。后续独立任务仍可重新学习；删除不清除旧会话历史、旧提示词快照或日志。不提供永久关闭记忆、跨群记忆或后台总结。

## 群设定

`/prompt` 查看设定，`/prompt set <内容>` 完整替换，允许多行、最多 4000 字符；`/prompt clear` 恢复默认。修改成功只回复“保存成功”。[配置与权限](configuration.md)规定修改权限及管理员身份。

群设定仅用于角色、语气和聊天方式，不能覆盖应用权限及隐私规则。设定、成员和群记录在重启、压缩及 `/new` 后保留。

## 更新时机

- 新群会话的 system 包含基础规则、bot QQ 号和群昵称、群模板、当前群设定及可选管理员身份。群模板、群设定、管理员或昵称变化需新建会话生效，可用 `/new` 或 `/new blank`；恢复、总结和压缩沿用原 system。
- 群聊每个独立 turn 前读取公共模板，并结合应用规则、图片交付说明、Pillow 路径、表情规则和全部名称、最新全群记忆及交接摘要形成 developer 快照。变化才更新，相同内容跨重启去重；新会话首次必注入。更新失败不提交新的用户任务。
- 手动、空闲及自动压缩后，下次独立 turn 补注入最新快照；轮前空闲压缩则在本轮开始前补注入。旧群会话也会补入更新后的规则与记忆，无须 `/new`。
- 最新快照替代旧快照作为规则与记忆依据，但不删除历史；它不包含群模板、群设定和管理员身份。当前 turn 的 steering 沿用当前规则，变更下个独立 turn 生效；普通消息和 steering 不附加偏好文本。
- 表情配置仅启动时加载，其名称列表参与快照比较。Nix 提示词资源或挂载变化需重新部署；公共模板更新在之后的独立 turn 生效。
- 私聊在新建和恢复时传入公共及私聊模板，不参与群快照机制；更新部署后的模板按重启 agent 再 `/new` 的方式使用。
- 私聊与群聊均不注入 runtime 的多 agent 角色及协作模式提示词，不提供插件推荐上下文和安装推荐工具；保留已安装插件与其他 developer 提示词。旧历史内容不会删除。

默认文件、覆盖方法及内置技能维护见 [技能与资源维护](../internal/resources.md)。

群聊运行时只说明背景与新消息的含义，不注入节奏配置、触发原因、退避状态或参与率提示；具体边界见 [群聊协议](groups.md)。已存在于旧 thread 的提示词不改写历史。
