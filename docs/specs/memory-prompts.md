# 记忆与提示词

## 群记忆

群记忆按群保存为文本条目，不再维护按成员 ID 区分的个人 profile，也不提供 `qq_member` 工具或 `/profile` 命令。条目可以包含有依据的成员兴趣、互动偏好及其他公开讨论内容；保留必要的成员归属，不把个人偏好推成全群共识。

默认最多 50 条，每条最多 40 个 Unicode 字符（按 Python `len()` 计数），每条附应用内部日期。参数按群配置，见 [配置与权限](configuration.md)。模型只看到文本，不获得日期、容量上限、日期刷新或淘汰规则。

所有记录都是可在群内讨论的背景，不是新的授权或工具指令。个人当前要求优先于旧记忆，个人边界优先于群一般偏好，自动记忆不能覆盖手工群设定。不将第三方转述、引用、玩笑或猜测写成事实；不记录真实姓名、私密联系方式、住址、证件、登录账号、凭据等敏感信息，不拼接现实身份线索。语义依靠模型规则约束，结构校验不能保证消除提示词注入或敏感内容。

`/group-profile` 查看全部文本，按字母序换行排列，不显示日期；`/group-profile forget` 清除，权限与群设定修改一致。清除等待正在排队或执行的总结结束，避免旧结果重新写回。后续总结仍可学习；删除不清除旧会话历史、旧提示词快照或日志。`/new` 保留群记忆。

## 定时总结

每群默认启用，每天系统本地时间 05:00 触发。周期为前一天配置时刻至本次配置时刻，左闭右开；时刻和开关可配置。启动只安排下一次未来触发，停机错过或中断的周期不补跑，同一周期不重复执行。没有可用 thread、会话已标记待新建或未登录时不创建新会话进行总结。

总结复用当前群聊 thread、当前模型和 medium。到点排队等待当前 turn 完成；总结及纠错期间新消息继续接收并沿用现有积压规则，不启动普通群聊 turn。不同群独立。会话重置、压缩与记忆修改不与总结并发；`/stop` 可取消等待或执行中的总结。

只使用当前可见上下文，不补入数据库历史。压缩或 `/new` 丢失的当天内容不保证覆盖。应用提供周期范围、全部记忆及从 1 开始的序号，整个纠错过程固定编号；请求仅返回：

```json
{"valid":[1,3,6],"new":["某成员喜欢明日方舟","某成员喜欢音乐游戏","其他有依据的内容"]}
```

`valid` 是仍有效的旧条目序号数组，不允许重复、越界或布尔值。`new` 是文本数组，去除首尾空白后必须至少有 3 条不同内容；每条非空、不含控制字符且不超过配置字数，不允许为凑数编造。只允许这两个必填字段；重复 JSON 字段无效。

完整成功后一次性更新：刷新 `valid` 条目到提交当天，未选中的旧条目保留原日期；新增条目标记提交当天，相同文本合并刷新。超额时按日期升序、同日按文本字母序升序剔除最前面的条目。

无效结果反馈错误并纠正，累计 3 次无效即熔断（首次计入，最多追加 2 次纠错请求）。成功前不写记忆；失败、超时或取消保留原记录，恢复普通群交互，不自动重跑。本次内部任务总超时为 `min(task_timeout, 900)` 秒。素材不足也可能熔断。

总结请求和结果保留在当前 thread，不发送 QQ 消息、提醒或故障通知；不提供 QQ 活动工具上下文，提示不调用工具或执行历史请求。日志记录结果。运行状态无法确认时沿用现有 runtime 重启保护。

## 群设定

`/prompt` 查看设定，`/prompt set <内容>` 完整替换，允许多行、最多 4000 字符；`/prompt clear` 恢复默认。修改成功只回复“保存成功”。[配置与权限](configuration.md)规定修改权限及管理员身份。

群设定仅用于角色、语气和聊天方式，不能覆盖应用权限及隐私规则。设定与群记忆在重启、压缩及 `/new` 后保留。

## 更新时机

- 新群会话的 system 包含基础规则、bot QQ 号和群昵称、群规则、当前群设定及可选管理员身份。system 规则、群设定、管理员或昵称变化需新建会话生效，可用 `/new` 或 `/new blank`；恢复、总结和压缩沿用原 system。
- 群聊每个独立 turn 前结合公共规则、图片交付说明、Pillow 路径、表情规则和名称、最新群记忆及交接摘要形成 developer 快照。群记忆按文本排序后换行连接；仅日期变化不影响快照。变化才更新，相同内容跨重启去重；新会话首次必注入。更新失败不提交任务。
- 手动及自动压缩后，下次独立 turn 补注入最新快照。旧群会话也会补入新规则与记忆，无须 `/new`。内部总结和纠错仅适用于当前内部任务，不改变后续普通回复协议。
- 最新快照替代旧快照作为规则与记忆依据，但不删除历史；它不包含群 system 规则、群设定和管理员身份。群聊任务期间的新消息进入下一批，记忆变化在下个独立 turn 生效；普通消息和私聊 steering 不附加记忆文本。
- 提示词随应用发布，修改后重新部署并重启。表情配置仅启动时加载，名称参与快照比较。
- 私聊在新建和恢复时传入公共及私聊规则，不参与群快照机制。
- 私聊与群聊均不注入 runtime 的多 agent 角色及协作模式提示词，不提供插件推荐上下文和安装推荐工具；保留已安装插件与其他 developer 提示词。旧历史内容不会删除。

提示词来源及内置技能维护见 [技能与资源维护](../internal/resources.md)。群聊运行时不注入节奏配置、触发原因、退避状态或参与率提示，见 [群聊协议](groups.md)。
