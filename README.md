# QQ Codex Agent

部署在树莓派上的个人 QQ AI 助手，通过 NapCat OneBot 11 连接 QQ，使用本地 Codex app-server 和 ChatGPT 登录。

支持自然语言问答、图片理解、图片生成和代码执行；读取运行时 AGENTS.md 定制提示词，使用 Approve for me 自动审批及受限文件系统。

- 私聊与各群独立授权，默认拒绝访问；群内支持指定用户或全员使用，须 @ bot。
- 各私聊、各群独立并发，处理中继续发送的消息通过 steering 追加到当前任务，在工具调用结束等可接收输入的位置处理。
- 私聊独立会话，同群共享上下文和模型；消息间隔超过两小时且上下文估算超过 100,000 tokens 时，在原 thread 压缩后再提交新消息。私聊和群聊在手动、空闲及自动压缩开始时均发送提示。`/new` 创建不携带历史的空白会话，保留工作文件。
- 自动压缩阈值为 200,000 tokens，`/compact` 可手动压缩空闲会话，保留原图和完整历史，不保证清除图片或降低总网络流量；成功追加消息后重置 15 分钟期限。空闲 thread 取消订阅后由 Codex 延迟回收。
- 群聊仅在 agent 调用发送工具时发送生成图片，群聊和私聊均在每条模型文字完成后按顺序发送，包括过程说明和最终回复；记录聊天偏好时提示“📝正在给{nickname}记进小本本……”，使用群名片，缺失时回退到昵称或 QQ 号；指令保留直接回复。
- 生成原图自动保存在会话工作区；`qq_image.list_images` 查询路径，使用 Pillow 加工多帧后通过 `qq_image.send_image(path=...)` 发送最终 GIF。每个聊天固定使用独立目录，图片跨轮及 `/new` 保留。服务启动及此后每 24 小时清理超过 14 天未访问或修改的文件，跳过忙碌聊天。
- 支持 `/help`、`/model`、`/status`、`/new`、`/stop`、`/compact`，推理强度固定为 `medium`。`/status` 显示登录、任务状态、最近的上下文 token 估算和用户消息数。
- 普通群聊任务通过登录检查后、处理引用和图片前，为触发消息添加一次 OK 表情；不等待表情请求返回。30 秒及 5 分钟提醒仍从启动 turn 时计时。
- 群聊会从本人明确偏好和反复出现的交流习惯记录聊天偏好，按群隔离，可更新当前群任意已确认成员，并记录群共同兴趣和互动习惯。每个独立任务开始前更新 developer 提示词中的全群最新记录，agent 尽可能遵守；普通消息和 steering 不附加偏好文本。重启、换 thread 和 `/new` 后数据库记录保留；不监听未 @ bot 的聊天，不增加后台模型调用。
- `/profile` 在当前群公开显示本人偏好；`/profile forget` 删除本人当前群偏好，当前任务不能写回该成员，旧聊天历史和 journal 仍保留，后续独立任务可能重新学习。`/group-profile` 查看群共同记录，`/group-profile forget` 清除。所有命令均须获该群授权并 @ bot。
- `/prompt` 查看群设定，`/prompt set <内容>` 替换，`/prompt clear` 恢复默认；最多 4000 字符，允许多行，下个独立任务生效，保存成功只回复“保存成功”。`group_prompt_allow_members` 默认 false，仅可交互用户中的群主、管理员能修改群设定或清除群记录；设为 true 后全部可交互用户可操作。
- 本仓库维护 Nix 包、服务模块及默认提示词；dotfile 维护宿主配置和版本锁，使用 agenix 管理白名单，Pi 无需单独 clone 本仓库。

两仓库接入、提示词覆盖及部署检查见 [nix/README.md](nix/README.md)。

开发、部署、登录及排障方法见 [AGENTS.md](AGENTS.md)。公共运行时模板见 [AGENTS.runtime.md](AGENTS.runtime.md)，私聊和群聊模板分别见 [AGENTS.private.runtime.md](AGENTS.private.runtime.md) 与 [AGENTS.group.runtime.md](AGENTS.group.runtime.md)。

成员记录保留现有 SQLite 表和字段，每人最多 500 字符，全群不做 2000 字符截断；群共同摘要最多 1000 字符，群设定单独保存。记录用于推进聊天，可保存本人明确表达的游戏、音乐、专业方向及主动提供、用于共同游戏的 Steam 公开标识；不记录真实姓名、私密联系方式、住址、证件、登录账号或凭据，不把第三方转述、玩笑或猜测写成事实，不把个人偏好推成全群共识。记录可在当前群公开查看，当前个人要求优先于旧记忆。

群聊使用简短基础提示词，保留文件操作、执行、网页搜索、QQ 图片交付及记忆工具说明；私聊保持 Codex 默认基础提示词。群设定仅用于角色、语气和聊天方式，不覆盖应用权限及隐私规则。运行中的任务和 steering 不切换设定；下一独立任务加载最新设定和记录，保留聊天历史。`/new`、重启和压缩不删除数据库设定或记忆。

消息收发、任务进度及真实错误可直接查看 `sudo journalctl -u qq-codex-agent -f -o cat`。日志包含聊天正文，避免公开分享；图片二进制不记录，常见凭据字段脱敏。
